# Success Criteria

The game will be considered successful if it meets the following criteria:

- **Creative story:** The game has an original and engaging story with its own characters, locations and lore.
- **Different enemies and bosses:** The game includes different enemy types and bosses with different names, stats and behaviours.
- **Application window:** The game runs inside a dedicated application window rather than only using the command line.
- **Visually appealing:** The game has a clear layout, readable text, health bars, menus and other visual elements that make it enjoyable to play.
- **Index:** The game includes an index that provides information about important characters, enemies, weapons, areas and other game elements.
- **Object-oriented programming:** The game's main systems, characters, enemies, weapons, areas, dialogue and inventory are organised using classes or objects where appropriate.
- **Functional gameplay:** The player can explore areas, interact with NPCs, collect and equip weapons, enter combat and progress through the game.

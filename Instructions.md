# SkyBorne — Instructions (Manual)

## How to Run the Game

### Requirements

* Python 3.14 or later
* Tkinter (included with most standard Python installations)
* A computer capable of running Python applications

### Starting the Game

1. Download or clone the **SkyBorne** project.
2. Open the project folder.
3. Run the main Python file:

```bash
python main.py
```

4. The game will open in a **Tkinter application window**.
5. Enter your commands into the text box and press **Enter**.

---

## Main Menu

When the game starts, the main menu provides several options:

* **1 — Start Game**
  Begins the main adventure.

* **2 — Credits**
  Displays the game credits.

* **3 — Developer Note**
  Displays a short message from the developer.

* **0 — Return**
  Returns to the previous menu where applicable.

---

## How to Play

SkyBorne is a text-based RPG. Most interactions are performed by entering commands into the input box.

Players can:

* Explore different locations.
* Talk to NPCs.
* Select dialogue options.
* Fight enemies.
* Attack enemies.
* Attempt to parry attacks.
* Flee from combat.
* Collect weapons and items.
* Equip weapons.
* Explore dungeons.
* Find hidden areas.
* Use safe areas to recover.
* Check the in-game **Index** for discovered information.

### Combat

During combat, the game provides information about the enemy's upcoming attack.

The player can choose actions such as:

* `attack`
* `parry`
* `flee`

Pay attention to enemy **tells**, as they provide clues about incoming attacks.

---

## Index

The game includes an **Index** containing discovered information about:

* Characters
* Enemies
* Weapons
* Locations

The Index can be used to learn more about the world as the player explores it.

---

## Game Progression

The general NORMAL progression of the game is:

```text
Oakhaven
    ↓
Ashenhollow
    ↓
Gloomwood Forest
    ↓
Ventus Azura
    ↓
Final Dragon Arena
```

Players must explore, fight enemies, collect equipment and progress through the world to reach the final encounter.

---

## Important

Some areas, characters, items and information are intentionally hidden.

**Exploration is part of the game.**

Not everything is immediately explained to the player, so talking to NPCs and checking the Index can help reveal more of the game's lore.
